# Gemini 프롬프트 메이커

고르기만 하면 Gemini가 잘 알아듣는 프롬프트로 바꿔 주는 연수용 홈페이지입니다.
`index.html` 파일 하나로 동작하며, 인터넷 연결, API 키, 설치가 필요 없습니다.

- **🖼️ 사진 프롬프트 메이커**: 아바타(나의 캐릭터) → 교직 일대기 장면 그림 → 자서전 표지·앨범 커버
- **🎬 동영상 프롬프트 메이커**: 스토리보드로 10초씩 이어지는 영상 (사진에서 시작, 컷 나누기, 대사·효과음)

첫 화면에서 둘 중 하나를 고릅니다. 바로 들어가는 주소도 있습니다.

- 사진: `https://hots-gg.github.io/storyboard_Gemini/#photo`
- 동영상: `https://hots-gg.github.io/storyboard_Gemini/#video`

사진 메이커의 장면 프롬프트 아래 **"🎬 이 장면 그림으로 영상 만들기"**를 누르면, 그 장면의 인물·장소·빛·분위기·화풍이 동영상 메이커의 기본 설정으로 넘어갑니다.

## 배포 방법 1: HTML 파일로 나눠 주기
`index.html`을 메일이나 메신저로 보내면, 선생님들이 파일을 더블클릭해 브라우저(크롬, 엣지)로 열면 됩니다.

## 배포 방법 2: GitHub Pages
저장소 **Settings → Pages**에서 Source를 **Deploy from a branch**, Branch를 **main / (root)**로 정하고 **Save**를 누릅니다.
`main`에 푸시하면 1~2분 뒤 사이트에 반영됩니다.

## 처음 쓰는 사람을 위한 기능
- **🪄 이야기 뼈대 마법사**: 처음 모습, 사건, 감정이 가장 큰 순간, 마지막 모습을 적으면 장면 3~4개와 카메라 설정을 자동으로 채워요. (장소 소개 → 사건 → 클로즈업으로 감정 강조 → 위로 솟아오르며 여운)
- **✨ 느낌으로 고르기**: 컷마다 '뭉클하게', '긴장되게' 같은 느낌을 고르면 화면 크기, 각도, 움직임, 초점이 한 번에 정해져요.
- **🎞 콘티 보기**: 장면과 컷을 만화 칸처럼 보여 주고, 콘티만 따로 인쇄할 수 있어요. 인공지능 없이 고른 내용만으로 그려요.

## 참고
- 입력한 내용은 각자 브라우저에만 저장됩니다.
- 예시(빈 교실의 노을, 졸업식 날)와 선택지는 `index.html` 안의 `EXAMPLES`, `SHOTS`, `MOVES` 등에서 고칠 수 있습니다.
- 카메라 움직임에는 줌 인, 돌리 줌, 휩 팬, FPV 드론 샷이 있고, 컷마다 초점(얕은 심도·랙 포커스·딥 포커스)과 컷 전환(하드 컷·휩 팬 전환·매치 컷·디졸브)을 고를 수 있어요. "감성 있게", "세련되게" 같은 막연한 말을 쓰면 연출 용어로 바꾸라고 알려 줘요. (참고: [AI 영상 퀄리티 높이는 용어 모음](https://www.fmkorea.com/best/10440879550))
- Gemini가 한 번에 만드는 영상 길이가 8초라면, 동영상 메이커의 '한 장면 길이'를 8초로 바꾸세요.
